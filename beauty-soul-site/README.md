# Beauty Soul KZ — сайт салона

Одностраничный сайт салона красоты Beauty Soul (Алматы, Аксай, 1, 15).
Vite + React + TypeScript + Tailwind CSS v4, компоненты в стиле shadcn/ui на Radix
(Dialog — мобильное меню и просмотр фото, ToggleGroup — фильтр работ).

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # готовый сайт в dist/
npm run preview   # посмотреть собранную версию
```

`dist/` — статический сайт: его можно загрузить на любой хостинг
(Netlify, Vercel, GitHub Pages, обычный веб-сервер). Пути относительные.

## Фотографии

Исходники лежат в `assets-src/` (подборка BeautySoul_site_assets).
Адаптивные версии (webp + jpg, ширины 480/800/1200/1800) и `og-image.jpg`
генерируются командой:

```bash
pip install pillow
npm run images
```

## Где менять тексты

Весь контент — в `src/content/site.ts`: услуги, работы, мастера, отзывы,
адрес, ссылки на запись и Instagram.

## Что нужно подтвердить у салона перед запуском

Сайт намеренно не содержит непроверенных фактов.

- **Мастера.** Имена «Аружан» и «Гульжан» взяты из подборки (IMAGE_MAP),
  специализации — по работам на фото. На снимках — работы мастеров, а не их портреты
  (`16_master_gulzhan.jpg` — тот же файл, что `05_hair_long.jpg`, поэтому в проект он
  не скопирован). Нужны подтверждение имён и специализаций и, если возможно, портреты.
- **Отзывы.** Массив `reviews` пуст: настоящих отзывов в переданных материалах нет.
  Раздел «Отзывы» пока опирается на реальные работы, салон и команду. Когда появятся
  настоящие отзывы (с согласия авторов), добавьте их в `reviews` — карточки выведутся сами.
- **Цены, часы работы, телефон** не указаны — не подтверждены.
- **Карта.** Кнопки «Открыть в 2ГИС / Яндекс Картах» ведут на поиск по адресу,
  без выдуманных координат. Если есть точная ссылка на карточку салона — замените в `brand.maps`.
- **Домен.** После подключения домена раскомментируйте `<link rel="canonical">`
  в `index.html` и укажите абсолютные адреса в `og:image` и JSON-LD.
