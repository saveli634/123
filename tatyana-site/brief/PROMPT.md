> Лежит в папке проекта вместе с `content/` (её тексты и стихи дословно). Открой Claude Code в этой папке и вставь строку из `START_HERE.txt`. Места `{{…}}` можно оставить: Claude Code поставит заглушки и перечислит их в отчёте.

# 1. Задача и роль

Ты — ведущий фронтенд-разработчик и арт-директор студии уровня Awwwards. Сделай **одностраничный сайт-визитку Татьяны: нумерологические расчёты по дате рождения, натальные карты, а ещё творчество: стихи и песни, которые она сочиняет.** Всё в **одном** сайте (она сама просит объединить астрологию, нумерологию и творческую часть, см. её голосовые). Стихи есть в её роликах в Instagram, песен в материалах пока нет. Сайт должен вызывать «вау» с первой секунды, быть **космическим фиолетовым** и при этом оставаться честным: без выдуманных фактов и без громких обещаний.

Материалы:
- `content/uslugi_istochnik.txt`: её текст об услугах (дословно);

Разбей на пять созвездий-тем: «Время и циклы» (1, 2, 3, 13), «Отношения» (5, 8, 10, 17, 18, 23), «Деньги и профессии» (7, 12, 16), «Предназначение и карма» (4, 6, 9, 11, 14, 15, 19, 20), «Семья и дети» (21, 22). Нижняя плавающая панель на телефоне: «Записаться» (если есть ссылка). Не должна перекрывать контент.

# 4. Дизайн и движение

**Концепция «Карта неба».** Космический фиолетовый, но не «кислотный» и не «дешёвый Таро». Ощущение: ночная обсерватория и тонкая золотая графика карты. Много воздуха, крупная антиква, тонкие линии, свечение только там, где важно.

**Палитра** (роли; контраст текста ≥ 4.5:1):
- `--void #070312` основной фон;
- `--nebula #1B0B3A` поверхности, облака туманности;
- `--cosmic #5B2BE0` главный космический фиолетовый (кнопки, свечение);
- `--lilac #A78BFA` вторичный акцент, линии созвездий;
- `--stardust #EDE4FF` основной текст;
- `--champagne #E6CF9A` тонкие линии карты и числа (не более 5% площади);
- `--magenta #C026D3` только как слабый оттенок туманности (≤ 8% прозрачности).

**Шрифты (кириллица обязательна, локально, subset):** заголовки и числа: Cormorant Garamond (в т. ч. курсив); текст: Manrope. **Знаки зодиака и планеты рисуй SVG-путями**, не эмодзи и не юникод-символами.

**Как соединить три сферы в одном сайте** (она прямо спрашивала об этом). Единая метафора **«музыка небесных сфер»**: карта = небо, число = его ритм, слово и песня = голос. Это один космос, четыре «планеты» (Карта · Число · Слово · Песня) на общей орбите: они же навигация сверху, они же значки секций, их орбиты видны на фоне. Ни одна сфера не выглядит «приклеенной»: у всех тот же звёздный фон, те же тонкие золотые линии, те же шрифты. Место встречи всех трёх: блок «Подарок на день рождения».

**Фон.** Canvas 2D: три слоя звёзд с разной скоростью (параллакс от прокрутки), редкие падающие звёзды (одна в 8–12 с), мягкая туманность из 3–4 размытых радиальных градиентов. Рисовать только пока вкладка активна; на слабых устройствах число звёзд автоматически уменьшать.

**Главная сцена «Небо в момент рождения»** (закреплена на 300 svh, `ScrollTrigger` + `Lenis`), SVG, WebGL не нужен:
- Этап 0: в центре тонкая окружность `champagne` рисуется (`stroke-dashoffset`).
- Этап 1: появляются 12 секторов (линии от центра), по внешнему кольцу проявляются 12 знаков зодиака по часовой стрелке.
- Этап 2: 10 планет-точек влетают по дугам на свои места (позиции декоративные, подпись мелко: «иллюстрация»), между ними прорисовываются линии-аспекты.
- Этап 3: по краю колеса поочерёдно загораются пять подписей из её текста: число, месяц, год, город, время. Колесо медленно поворачивается, в центре «Ваша карта неба».
- Реализация: один массив параметров (углы, радиусы, фазы), одна функция отрисовки от `progress ∈ [0,1]`, `requestAnimationFrame` только пока секция на экране.
- Fallback без JS / reduced-motion: статичное готовое колесо.

**Интерактив «Узнай своё число»** (считается в браузере, ничего не отправляется и не сохраняется; рядом честная строка «Дата не отправляется и не сохраняется»):
- ввод даты рождения (`input type="date"` + запасной ввод ДД.ММ.ГГГГ);
- результат: **число даты рождения** (сумма всех цифр даты до однозначного, 11/22/33 не сворачивать), **персональный год** (день + месяц + текущий год, так же) и **знак зодиака по дате** (стандартные границы);
- числа выводятся крупно, с красивой «сборкой» цифр, по нажатию «расчёт» вспыхивает звезда;
- **толкований не показывать вообще.** Подпись: «Это только число. Что оно значит именно для вас, я расскажу на расчёте». Если схема подсчёта у Татьяны другая, это нужно уточнить: перечисли в отчёте как «уточнить у Татьяны».

**Остальные эффекты:**
1. параллакс звёзд и туманности при прокрутке;
2. курсор оставляет короткий звёздный след (только `hover: hover`);
3. магнитные кнопки (притяжение 6–10 px);
4. строки стихов проявляются построчно с лёгким размытием → резкость;
5. бегущая лента «число · месяц · год · город · время» со скоростью от скорости прокрутки;
6. тонкая полоса прогресса сверху в виде орбиты;
7. карточки «что покажет карта» с 3D-наклоном за курсором.

**Принципы движения:** только `transform` и `opacity` (и `stroke-dashoffset` у SVG); один набор easing: появление `cubic-bezier(0.22, 1, 0.36, 1)`, перемещение `cubic-bezier(0.4, 0, 0.2, 1)`; 300–700 мс; без мигания и отскоков.

# 5. Техника

- Vite + React + TypeScript + Tailwind; Lenis (только мышь/тачпад); GSAP + ScrollTrigger.
- **Звук:** файлы из `content/pesni/` сжать в mp3 ~128 кбит/с (моно допустимо) и положить в папку `audio/` рядом с `index.html`; `preload="none"`, имя файла без кириллицы. В файле `sait.html` (для отправки) звук **не встраивать**: страница работает без него, плееры скрываются, если файлов нет; в сборке для хостинга папка `audio/` лежит рядом и всё играет. Если суммарно звук ≤ 2 МБ, можно встроить в файл. Объясни это в отчёте простыми словами.
- **Один HTML-файл, открывается двойным щелчком без интернета** (`vite-plugin-singlefile`, шрифты урезаны до кириллицы и латиницы, ≤ 5 МБ) + обычная сборка для хостинга. Картинок почти нет, всё векторное и canvas.
- **Пререндер**: текст виден сразу, без белого экрана, даже если скрипты не запустились. Скрытые до появления элементы прячутся только при классе `.js` на `<html>` с запасным таймером 2 с.
- Совместимость: es2017, Safari 12+, без `@layer`.
- Мета: `<title>` «Татьяна — нумерология и натальная карта», description из её слов, Open Graph (сгенерируй картинку из колеса), `lang="ru"`, фавикон: маленькая звезда.

# 6. Телефоны (iPhone и Android)

- Все эффекты работают, адаптированы под вертикальный и горизонтальный экран.
- Закреплённые сцены в `svh`, без скачков при скрытии адресной строки.
- При низком fps (< ~45 подряд) автоматически: меньше звёзд, без следа курсора, упрощённые аспекты.
- Цели нажатия ≥ 44×44 px, основной текст ≥ 16 px; поле даты удобно вводится с цифровой клавиатуры.
- В отчёте объясни: в предпросмотре мессенджеров и «Файлов» на iPhone скрипты не работают, открывать нужно в браузере или на хостинге.

# 7. Доступность

`prefers-reduced-motion`: отключить закреплённые сцены, падающие звёзды и параллакс, всё читается статично. Видимый фокус, управление «созвездием» с клавиатуры (Tab/стрелки), `aria-live` у результата калькулятора, `alt`/`aria-label` у значимых SVG, декор `aria-hidden`.
