# Soft Line — сайт шоурума диванов

Одностраничный сайт шоурума Soft Line (ТЦ ADEM 1, 3 этаж, оранжевый сектор, Алматы).
Vite + React + TypeScript + Tailwind CSS v4, примитивы в стиле shadcn/ui на Radix
(Dialog — мобильное меню и карточка модели, ToggleGroup — фильтр), иконки Lucide.

## Запуск

```bash
npm install
npm run dev            # разработка
npm run build          # сайт для хостинга -> dist/ (пререндер: разметка видна без JS)
npm run build:single   # один файл -> dist-single/index.html (открывается двойным кликом)
```

Фото: исходники в `assets-src/`, адаптивные версии — `npm run images` (нужен Pillow).
Перед публикацией фото обрезаются (`scripts/crops.py`): убраны вшитые надписи
«@soft.home.kazakhstan OSCAR», интерфейс видео, стикер и вывеска соседнего магазина.

Весь контент — `src/content/catalog.ts`: модели, описания, телефоны, ссылки.

## Что намеренно НЕ указано (нет подтверждения в материалах)

- Цены — везде «Цена по запросу» / «Узнать цену» (WhatsApp с готовым сообщением).
- Размеры, материалы, страна производства и механизмы моделей — подписей постов
  в архиве нет; описания моделей составлены только по тому, что видно на фото.
  Когда появятся данные — дополните `details` у нужной модели.
- Категории фильтра — только «Прямые» и «Угловые» (по фото). Модульные и комплекты
  не подтверждены. У Big Boss тип не определён — модель видна только в «Все модели».
- Часы работы, гарантии, отзывы, статистика.
- Бесплатная доставка по Алматы — с пометкой «для моделей, где это указано».

  @soft.home.kazakhstan (водяной знак на фото). Подтвердите основной аккаунт.
