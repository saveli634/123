Сюда — скриншоты отзывов (PNG или JPG). Порядок на сайте — по имени файла (01.png, 02.png, ...).
Затем: npm run media && npm run build:all — блок «Отзывы» появится сам (пока папка пуста, его на сайте нет).

Перед публикацией закрой имена и аватарки клиентов или получи их согласие.
Замазать можно автоматически: файл blur.json рядом, например
  {"01.png": [[40, 120, 520, 190]]}
— прямоугольники [x0, y0, x1, y1] в пикселях скриншота, которые нужно размыть.
