# Автосервис «У Грека» — сайт

Одностраничный сайт автосервиса и автомагазина (Алматы, проспект Рыскулова, 174А).
Vite + React + TypeScript + Tailwind CSS v4, примитивы shadcn-стиля на Radix (Dialog — меню,
форма-заявка, просмотр фото), иконки Lucide. Шрифты Oswald / Inter / JetBrains Mono (только
кириллица и латиница).

## Отличия от брифа (осознанно)

- **Стек.** В репозитории уже есть стек Vite + React (бриф: «переиспользовать существующий»),
  и сайт должен открываться одним файлом с диска. Поэтому не Next.js: страницы услуг — разделы
  с якорями на главной (бриф допускает такой вариант), отдельных маршрутов `/uslugi/*` нет.
- **Форма.** Серверного `/api/lead` в статической сборке нет. Если при сборке задан
  `VITE_LEAD_WEBHOOK_URL`, заявка уходит POST-запросом (JSON) на этот адрес, и только тогда
  показывается «Заявка отправлена. Мы перезвоним вам.». Без него форма проверяет поля
  и открывает WhatsApp с готовым текстом заявки — форма никогда не тупик.
- **Картинки.** Пайплайн на Python/Pillow (`scripts/build_images.py`) вместо sharp: WebP
  в нескольких ширинах + одна JPG-запаска. AVIF не генерируется.
- **Sitemap / canonical** — добавить после подключения домена (нужны абсолютные адреса).

## Движение и 3D

Бриф изначально просил обойтись без 3D; по последнему запросу владельца добавлены 3D и эффекты прокрутки.

- **«Каждый узел — наша работа»** (`CarShowcase.tsx`, `src/three/`): процедурная 3D-модель внедорожника на Three.js. При прокрутке машина разбирается по направлениям сервиса (обвес, кондиционер, двигатель, печка, ходовая), камера облетает её. Three.js грузится лениво, рисует только пока раздел на экране.
- Плавная прокрутка Lenis (только мышь/тачпад), полоса прогресса вверху.
- Первый экран: фото уходит в глубину, строки заголовка разъезжаются, слои смещаются за курсором.
- «Аварийная лента» с услугами — скорость от скорости прокрутки (`HazardTape.tsx`).
- Фото проявляются «шторкой», в услугах — параллакс внутри кадра; работы «встают» в 3D и наклоняются за курсором.
- Стрелочный указатель температуры печки (первый замер из публикаций, 20° → 57°).
- Силовой обвес — закреплённая галерея-«карусель» (телефон, планшет, компьютер).
- Шаги «Как мы работаем» загораются по очереди.

Без WebGL — карточки с фото вместо 3D; при «уменьшить движение» и без JS — статичная вёрстка, весь текст и фото на месте.

## Запуск

```bash
npm install
npm run dev
npm run build          # dist/ — для хостинга (пререндер: разметка видна без JS)
npm run build:single   # dist-single/index.html — один файл, открывается двойным кликом
npm run images         # пересобрать фото из source-media/ (нужен Pillow)
npm run fonts          # пересобрать src/fonts.css
```

Переменные окружения (необязательно): `VITE_LEAD_WEBHOOK_URL` — адрес приёма заявок.

## Фото

`source-media/` — подборка из Instagram (в git не хранится: в оригиналах видны госномера; положите папку `pack/` из архива сюда). `scripts/image_map.py` — какие фото используются,
их имена, обрезка и **зоны размытия госномеров** (найдены вручную, результат проверен глазами).
Не используются: AI-постеры, фото с текстом-оверлеем (кроме обрезанного кадра геометрии),
маленькие превью, фото термометров (без подписей нельзя сопоставить кадр и цифры), лица.

## Где править

- `src/data/site.config.ts` — название, адрес, телефон, WhatsApp, часы (`hours: null`), соцсети.
- `src/data/services.ts` — услуги, факты, ориентировочные цены, телефоны отделов.
- `src/data/works.ts`, `equipment.ts`, `heater.ts`, `faq.ts` — галерея, оборудование, замеры, вопросы.
