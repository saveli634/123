# «Ночной глянец» — сайт мастера по ресницам (Минск)

Одностраничный сайт-визитка: ламинирование и наращивание ресниц. Тёмная чернильно-фиолетовая сцена,
белая каллиграфия из её же постов, ресница — главный мотив. Все тексты — только из её подписей
(см. `REPORT.md`, таблица «фраза → источник»).

## Что отдать

| Файл | Зачем |
|---|---|
| `sait.html` | **Один файл** (1,7 МБ): всё встроено — фото, ролик, шрифты. Открывается двойным щелчком без интернета. Можно переслать. |
| `dist/` | Версия для хостинга: та же страница, но фото и ролик отдельными файлами — грузится быстрее. Залить папку целиком на любой статический хостинг (Netlify Drop, GitHub Pages, Vercel и т. п.). |

**Важно про телефон.** В предпросмотре (приложение «Файлы» на iPhone, просмотр вложения в Telegram/WhatsApp)
скрипты не работают: видны тексты и фото, но без анимаций, интро и сцены «Подъём». Чтобы увидеть всё —
открыть файл в Safari/Chrome («Поделиться» → «Открыть в…») или выложить `dist/` на хостинг и открыть ссылку.

## Где править данные

Всё в одном месте — `src/site.config.ts`:

- `brand` — название латиницей (сейчас «Lash» — её надпись из поста; есть готовая векторная «Angel»; любое
  другое слово будет набрано каллиграфическим шрифтом);
- `masterName` — имя (пусто — не выводится);
- `booking` — Instagram, Telegram, WhatsApp, телефон: кнопка появляется только у заполненного канала,
  «Позвонить» — только если есть номер. Пока всё пусто, кнопка записи ведёт на её пост в Instagram;
- `address` — адрес/район (пусто — блок «Где принимаю» скрыт);
- `prices` — цены (пустой список — блок «Цены» скрыт; вёрстка готова).

После правки: `npm run build:all` — обновятся `dist/` и `sait.html`.

## Сборка

```bash
npm install
npm run dev          # просмотр с автообновлением
npm run build        # dist/ — для хостинга (разметка готова заранее: текст виден без скриптов)
npm run build:single # sait.html — один файл
npm run build:all    # оба варианта
npm run media        # пересобрать фото, ролик и векторные надписи из assets-src/ (нужны Pillow и ffmpeg)
npm run fonts        # пересобрать src/fonts.css (только кириллица + латиница)
```

Стек: Vite + React + TypeScript + Tailwind, GSAP + ScrollTrigger, Lenis (плавная прокрутка только для
мыши/тачпада). Без аналитики, форм, внешних скриптов, шрифтов и CDN — всё локально.

## Как устроено

- **Интро** (≤ 1,5 с, только первый заход в сессии): название «пишется» штрихом, «веки» раскрываются.
  Целиком на CSS — не ждёт скриптов. Пропускается при «уменьшить движение».
- **«Подъём»** (`LiftScene.tsx`, `lib/lashes.ts`, `lib/liftRenderer.ts`): закреплённая сцена на 280svh,
  canvas 2D. Один массив параметров ресниц и одна функция состояния от прогресса прокрутки: ресницы лежат →
  выкладываются на валик → поднимаются, глаз открывается, на кончиках блики → «Поднимаю взгляд за час».
  Рисует только пока сцена на экране. Если кадры медленные (< ~45 fps две секунды подряд) — 24 ресницы
  вместо 40 и без свечения за курсором. Без скриптов — та же геометрия статичной SVG-картинкой.
- **До/после**: фото 003 разрезано по белой полосе и выровнено по зрачку. Ползунок — мышь, палец, стрелки;
  при входе в секцию «после» проявляется само.
- **Процедура**: горизонтальный закреплённый таймлайн, линия-ресница зажигает шаги.
- Ещё: параллакс макро-фото, лента со скоростью от прокрутки, «шторки», 3D-наклон карточек с голографической
  кромкой (на телефоне — покачивание), галерея с перетаскиванием и инерцией, счётчики, прогресс-ресница сверху,
  магнитные кнопки, нижняя панель «Записаться» на телефоне.
- Закреплённые сцены сделаны на `position: sticky` + единицы `svh` — без скачков, когда прячется адресная строка.
