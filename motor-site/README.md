# Моторный цех (Алматы) — сайт

Одностраничный сайт моторного цеха: капитальный ремонт 1VD‑FTV (Land Cruiser 200, Lexus LX450d),
Land Cruiser 105. Одна идея на всю страницу — V8-дизель разбирается и собирается при прокрутке.

Vite + React + TypeScript + Tailwind CSS v4, компоненты в стиле shadcn/ui на Radix (диалог записи,
поля формы, кнопки), Three.js (процедурная модель мотора, без внешних файлов), Lenis (плавная
прокрутка только на мыши/тачпаде). Шрифты Oswald и Manrope из @fontsource — только кириллица и латиница.

## Что заполнить

`src/config.ts` — название, адрес, часы работы, телефон, WhatsApp, Instagram, ссылка на карту,
флаги `showFaces`, `showCommunities`, `showHardkorr`, `showGearbox`.

* Пустое поле → элемент не выводится. В обычной (демо) сборке на его месте видна плашка «ЗАПОЛНИТЬ: …».
* `npm run build:release` останавливается, если пусты `name`, `phone` или `whatsapp`, и собирает
  сайт без плашек.
* Ссылки на ролики «Разборов» (из `source_url.txt`) — `src/content/copy.ts`, поле `url` в `TOPICS`.
  Пока ссылки нет, карточка ведёт в Instagram цеха (если он заполнен).
* Весь текст сайта — `src/content/copy.ts`. Источник каждой строки — в отчёте (`release/ОТЧЁТ.md`).

Готовые файлы для отправки — в `release/`: `site.html` (один файл), `dist/` (хостинг), скриншоты «до/после», отчёт.

## Команды

```bash
npm install
npm run dev            # разработка, http://localhost:5173 (схема мотора отдельно: /render.html?t=2.5)
npm run build          # dist/ (хостинг) + dist-single/index.html (один файл)
npm run build:release  # то же, но проверяет CONFIG и убирает плашки «ЗАПОЛНИТЬ»
npm run renders        # готовые рендеры мотора (renders/*.png) и картинка Open Graph (public/og/og.jpg)
npm run images         # фото: размытие чужих логотипов и людей, единый грейд, WebP
npm run shots r2       # скриншоты для проверки: 6 размеров × 5 режимов (shots/r2, в git не хранится)
npm run lighthouse     # Lighthouse (телефон) на dist/ → release/lighthouse
python3 scripts/fonts.py   # пересобрать шрифты (нужен pip install fonttools brotli)
```

После изменения сцены (`src/three/*`) пересоберите рендеры, затем фото: `npm run renders && npm run images`.

## Как устроено

* **Пререндер.** HTML страницы собирается заранее (SSR), поэтому весь текст и фото видны без скриптов.
  Скрытые до появления элементы прячутся только при классе `.js` на `<html>`; если скрипты не
  запустились за 2 с, класс снимается и всё показывается.
* **3D.** Один холст на весь экран (`EngineLayer`): мотор с первого экрана переезжает в закреплённую
  сцену из шести этапов (500svh). Three.js грузится лениво (на компьютере — после загрузки страницы,
  на телефоне — при первом касании или на подходе к сцене), рисует только пока сцена на экране и
  стоит на скрытой вкладке. При просадке ниже 40 кадров/с за 2 с снижает pixelRatio и детализацию.
* **Без WebGL 2, при «уменьшить движение», без скриптов** — готовые рендеры той же модели
  (общий вид + 6 этапов), снятые скриптом `render-engine.mjs` в headless Chromium.
* **Фото.** Скрипт `images.mjs` (sharp) размывает зоны из `scripts/image-map.mjs` (чужие логотипы,
  люди на заднем плане, силуэт за стеклом) и делает единый грейд: контраст +12 %, насыщенность −22 %,
  яркость −8 %, тени в красно-чёрное. Поверх в CSS — красный multiply-градиент, зерно, виньетка.
  Кадры из видео показываются только «окнами» со срезанным углом, крупно — только фото 1440×1920.
* **Один файл.** `dist-single/index.html` — скрипты, стили, шрифты и фото внутри (каждое фото один
  раз, в CSS-классе). Открывается двойным щелчком без интернета, до 5 МБ.
* **Типографика.** Неразрывные пробелы после предлогов и союзов, перед тире, в числах — функцией
  при сборке (`scripts/typograph-plugin.ts` → `src/lib/typograph.ts`). Цифры счётчиков — гарнитура
  «Motor Digits» из Oswald с одинаковой шириной цифр (в самом Oswald нет табличных цифр).
* **Старые браузеры.** Скрипты — ES2017, CSS без `@layer` (scripts/compat.mjs), цель — Safari 12+.

## Важно про предпросмотр

Во встроенных просмотрщиках (приложение «Файлы» на iPhone, предпросмотр в мессенджерах) скрипты не
работают: видна статичная версия с готовыми рендерами мотора, весь текст и фото на месте. Живой 3D,
плавная прокрутка и анимации — в браузере (Safari, Chrome) или на хостинге.

## Хостинг

Содержимое `dist/` — на любой статический хостинг. После подключения домена укажите абсолютный адрес
картинки `og:image` и `<link rel="canonical">` (в `scripts/html-plugin.ts`).
