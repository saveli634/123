# Татьяна — «Карта неба». Сайт-визитка

Одностраничный сайт Татьяны: нумерологический расчёт по дате рождения, натальная карта и стихи из её роликов.
Космический фиолетовый, тонкая золотая графика. Все визуальные элементы нарисованы кодом: звёздное небо на canvas, «затмение» с орбитами, натальное колесо, созвездия. Фотографий на сайте нет.

- **`sait.html`** — сайт одним файлом (≈ 920 КБ): открывается двойным щелчком, работает без интернета.
- **`dist/`** — версия для хостинга (`npm run build`). Текст уже вписан в HTML, поэтому он виден сразу, даже до запуска скриптов.
- `brief/` — ТЗ и тексты Татьяны (дословно), по которым сделан сайт.

> **iPhone и мессенджеры.** Во встроенном предпросмотре Telegram, WhatsApp и в приложении «Файлы» скрипты не запускаются.
> Там сайт покажется статичным: текст и графика на месте, но без анимации, калькулятора и звёзд.
> Чтобы увидеть всё, откройте файл в Safari или Chrome («Открыть в…») либо выложите `dist/` на хостинг
> (Netlify Drop, GitHub Pages, любой статический хостинг).

## Что на странице

1. **Интро (1,5 с)**: звёзды зажигаются по одной, линии собирают созвездие, проявляется «Татьяна». Показывается только при первом заходе в сессии и не показывается при «уменьшить движение».
2. **Первый экран**: заголовок «Карта, которая объясняет, зачем вы здесь», «затмение» с тремя орбитами и планетами (планеты заходят за диск и выходят из-за него), свечение и слои за курсором. На телефоне свечение и слои слегка «дышат» сами.
3. **«Небо в момент рождения»** — закреплённая сцена на 300svh. Пока страница прокручивается, рисуется колесо: окружности → 12 секторов и знаков по часовой → 10 планет влетают по дугам, между ними прорисовываются аспекты → загораются пять подписей «число · месяц · год · город · время», в центре — «Ваша карта неба». Рядом сменяются четыре подписи из её текста.
4. **Бегущая лента** «число · месяц · год · город · время». Её скорость зависит от скорости прокрутки.
5. **«Что покажет карта»**: 8 тезисов из её текста. На компьютере карточки медленно вращаются по орбите: при наведении вращение останавливается, карточка наклоняется в 3D, есть кнопка «Остановить вращение». На телефоне это вертикальная «орбита» с параллаксом.
6. **«Узнайте своё число»**: дату можно ввести с цифровой клавиатуры (точки ставятся сами) или выбрать в календаре. Показывает число даты рождения, персональный год и знак зодиака. Цифры прокручиваются, как барабан, вспыхивает звезда, ниже видно, как получилось каждое число. Толкований нет.
7. **«Созвездие вопросов»**: 23 расчёта, разбитые на 5 созвездий. Наведение, касание или фокус звезды показывает формулировку, а линии созвездия загораются бегущим светом. С клавиатуры: Tab и стрелки ←/→, Home/End. Ниже — тот же список аккордеоном.
8. **«Что нужно для карты»**: пять ключей загораются по очереди при прокрутке. Рядом блок про ректификацию: стрелки циферблата бегут и останавливаются.
9. **Стихи**: две карточки-«свитка», строки проявляются по одной (размытие → резкость), у каждой кнопка «Смотреть ролик».
10. **Запись**: появится, как только будет хоть один канал записи (см. ниже).
11. **Подвал**: имя, дисклеймер, год (берётся из JS).

Ещё есть звёздный след за курсором (только мышь), магнитные кнопки (притяжение до 8 px), полоса прогресса сверху в виде орбиты с планетой, плавная прокрутка Lenis (только мышь и тачпад; на телефонах прокрутка родная), меню на телефоне.

## Телефоны, планшеты, компьютер

- Вёрстка проверена на ширине 360, 375 и 390 (вертикально), 844×390 (горизонтально), 768 (планшет), 1280 и 1440. Горизонтальной прокрутки нет.
- Закреплённая сцена сделана на `position: sticky` в единицах `svh`: при скрытии адресной строки в Safari и Chrome она не скачет. На вертикальном телефоне порядок «заголовок → колесо → подпись», на горизонтальном — колесо слева, текст справа.
- Если частота кадров долго держится ниже ~45 fps, качество снижается само: меньше звёзд, нет следа курсора, меньше аспектов, нет размытия строк. На слабых устройствах (по числу ядер и памяти) качество понижено сразу.
- Все цели нажатия не меньше 44×44 px, основной текст не меньше 16 px. Учтены «чёлка» и нижняя полоса iPhone (`safe-area`). Поле даты не вызывает зум на iPhone.
- Canvas рисует только при открытой вкладке. Когда ничего не движется, мерцание идёт 30 кадров в секунду, чтобы беречь батарею.

## Что заполнить, когда появятся данные

Всё недостающее собрано в `src/data/site.config.ts`. Пустые поля на сайте не показываются: нет ни пустых ссылок, ни пустых блоков.

| Метка из ТЗ | Где | Что будет, когда заполнят |
|---|---|---|
| `{{SURNAME}}` | `surname` или `VITE_SURNAME` | фамилия в шапке первого экрана и в подвале |
| `{{BOOKING_URL}}` | `booking.instagram / telegram / whatsapp / phone` или `VITE_INSTAGRAM`, `VITE_TELEGRAM`, `VITE_WHATSAPP`, `VITE_PHONE` | появятся блок «Записаться на расчёт», кнопки «Написать в Instagram» и т. д., «Записаться» в шапке, в меню, под калькулятором и нижняя панель на телефоне |
| `{{CITY}}` | `city` или `VITE_CITY` | строка с городом в блоке записи |
| `{{PORTRAIT}}` | файл `src/assets/portrait.jpg` (или .webp/.png) | круглый портрет в блоке записи; подхватывается сам |
| `{{PRICES}}` | `prices: [{ name, price }]` | блок «Цены» в блоке записи |

Пока каналов записи нет, на первом экране вместо «Записаться на расчёт» стоят «Узнать своё число» и «Как это работает». Блок записи с тестовыми данными проверен отдельно: на компьютере, на телефоне, в меню и в нижней панели.

## Что уточнить у Татьяны

1. **Фамилия**: показывать ли её на сайте.
2. **Канал записи**: Instagram, Telegram, WhatsApp, телефон (любые сочетания).
3. **Город** (или «онлайн»).
4. **Фото для портрета**: нужно ли оно и какое.
5. **Цены**: показывать ли их.
6. **Схема подсчёта чисел.** Сейчас так: *число даты рождения* — сумма всех цифр даты, сворачиваем до однозначного, 11/22/33 не сворачиваем (в том числе на промежуточном шаге: 29 → 11). *Персональный год* — цифры дня, месяца и текущего года, сворачиваются так же. *Знак* — по стандартным западным границам (Овен с 21.03, Телец с 20.04, Близнецы с 21.05, Рак с 21.06, Лев с 23.07, Дева с 23.08, Весы с 23.09, Скорпион с 23.10, Стрелец с 22.11, Козерог с 22.12, Водолей с 20.01, Рыбы с 19.02). Если у неё схема или границы другие, правка в одном файле: `src/lib/numerology.ts`.
7. **Согласие на публикацию обоих стихов** и ссылок на ролики.
8. **Опечатки в стихах** (на сайте не исправлены, текст дословный):
   - «В **ирах** прививают знания они» → «в **играх**»?
   - «совсем не **скушны**» → «не **скучны**»?
   - «Очень **не лёгкий** труд» → «**нелёгкий**»?
   - «не остановился ты **на пол пути**» → «**на полпути**»?
   - «По мнению деток **,** так и родителей» — лишний пробел; возможно, «**Как** по мнению деток, так и родителей»?
   - «Людям помогай и понимай **,**» — лишний пробел перед запятой.
   - «Айналайн**-** лучший», «наши**-** совсем», «актёрский**-** живой», «покой**-**» — дефисы вместо тире?
   - «Развивай пожалуйста таланты» — запятые вокруг «пожалуйста»?
   - «А коллектив наш, ну просто 🔥,» — эмодзи по ТЗ убран, но он заменял слово. Сейчас строка «ну просто,». Может, «ну просто **огонь**»?
   - «‼️» и «⁉️» — это знаки препинания в виде эмодзи, на сайте они стали «!!» и «?!». Оставить так или убрать?
   - «Айналайн» оставлен как в её тексте (по-казахски чаще пишут «Айналайын»). Проверить написание.
9. **Дисклеймер в подвале**: «Консультации носят информационный характер и не заменяют советов врача, юриста или финансового консультанта». Согласовать формулировку.

## Отличия от ТЗ (осознанно)

- **Закрепление сцен** сделано через `position: sticky` (в `svh`), а прогресс считает ScrollTrigger. Это не `pin` из GSAP: так на телефонах ничего не скачет при скрытии адресной строки.
- **Tailwind** даёт сброс стилей, тему (цвета, шрифты) и утилиту `sr-only`. Сами компоненты оформлены обычным CSS в `src/index.css`: дизайн штучный, так его проще читать.
- **Скиллы** `frontend-design`, `emil-design-eng` и `web-design-guidelines` в этой среде не установлены. Вместо финального аудита — свой список (фокус, клавиатура, контраст, цели нажатия, `prefers-reduced-motion`, `aria`) и Lighthouse.
- **Бегущая лента** без кнопки паузы: она декоративная (`aria-hidden`), при «уменьшить движение» стоит.
- **Lighthouse** мерился на локальном сервере с gzip-сжатием, как на любом хостинге. Без сжатия оценка заметно ниже.
- **В сборке для хостинга** стили встроены в `index.html`, чтобы первый экран отрисовывался на один запрос раньше.

## Где править

- `src/data/site.config.ts` — фамилия, каналы записи, город, цены (портрет — файлом в `src/assets/`).
- `src/data/content.ts` — тексты разделов, 23 расчёта и созвездия (координаты звёзд и линии).
- `src/data/poems.generated.ts` — стихи; генерируются из `brief/content/stihi_istochnik.md` командой `npm run poems`.
- `src/lib/numerology.ts` — схема подсчёта и границы знаков.
- `src/components/Wheel.tsx` — параметры натального колеса (углы, радиусы, фазы сцены).

## Сборка

```bash
npm install
npm run dev            # разработка
npm test               # проверка калькулятора
npm run build          # dist/ — для хостинга (пререндер, стили встроены)
npm run build:single   # dist-single/index.html и sait.html — один файл
npm run fonts          # пересобрать src/fonts.css (только кириллица и латиница)
```

Совместимость: синтаксис скриптов ES2017 и CSS для Safari 12+ (вложенность и `@layer` разворачиваются при сборке).
