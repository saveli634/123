# Отчёт: сайт «Ночной глянец»

## Что сделано

Одностраничный сайт мастера по ламинированию и наращиванию ресниц в Минске, по ТЗ из `PROMPT.md`,
во второй версии — с упором на «дорогой» вид (приёмы из «Папки читов»: Awwwards-подача, Silk/Aurora-фоны
в духе React Bits и Aceternity, раскрывающиеся кадры, курсор, тексты по словам).

Порядок: интро с «пишущимся» названием → первый экран с живым «шёлком» и фото в «глазе-миндале», который при
прокрутке раскрывается на весь экран → «Подъём» (ресницы поднимаются при прокрутке) → лента → до/после →
услуги (карточки с фото) → как проходит ламинирование (горизонтальный таймлайн с рисующимися иллюстрациями
шагов) → почему ко мне (стопка карточек со значками и счётчиками) → работы (галерея + ролик) → отзывы
(скриншоты; блок появляется, когда добавлены её настоящие скриншоты) → запись (на «шёлке») → подвал
(огромная каллиграфия «пишется»).
Всё работает на iPhone и Android вертикально и горизонтально — эффекты адаптированы, а не урезаны.

### Третья версия: телефон = компьютер

- **Анимации на телефоне не пропадают.** Раньше в предпросмотре файла (без скриптов) и при медленной загрузке
  страница оставалась статичной. Теперь основные эффекты продублированы на чистом CSS (интро, «сияние», раскрытие
  «миндаля» при прокрутке, подъём ресниц, лента, до/после, счётчики, иллюстрации, подвал), а запасной режим
  включается только при реальной ошибке скрипта.
- **Эффекты «от мыши» получили версии «от пальца»**: «шёлк» тянется за пальцем, наклон карточек при касании,
  световой круг от касания, нажатие кнопок, подсказка-свайп у галерей.
- **Отзывы скриншотами**: блок, рамки телефона, просмотр крупно (свайп, стрелки, клавиатура), автоматическое
  размытие имён/аватарок по `blur.json`. Скриншотов пока нет — блок скрыт, отзывы не выдумываются.
- **Чётче и аккуратнее**: фото в однофайловой версии — в родном разрешении; иллюстрации в шагах процедуры и
  значки в причинах вместо пустых полей; «глаз» на первом экране больше не наезжает на текст на маленьких
  телефонах (проверено 320×568, 360×780, 375×667, 390×844, 430×932).

## Что проверено

Скриншоты Playwright (Chromium) на 1440×900, 1280×800, 430×932, 390×844, 375×667, 360×780, 320×568,
844×390 (телефон горизонтально); первый экран и «Подъём» — на нескольких стадиях прокрутки.

| Режим | Результат |
|---|---|
| Обычный (хостинг, `dist/`) | всё работает; нет горизонтальной прокрутки; ошибок в консоли нет |
| Файл с диска (`sait.html`, `file://`) | то же: «шёлк», курсор, окно «Конфиденциальность»; ролик встроен и передаётся в плеер целиком |
| «Уменьшить движение» | без интро, закреплённых сцен и параллакса; «шёлк» — один неподвижный кадр; весь текст и фото видны сразу |
| Без JavaScript (так выглядит предпросмотр файла на iPhone) | анимации на CSS: интро, «сияние», «миндаль» раскрывается при прокрутке, ресницы поднимаются, лента бежит, ползунок до/после ходит сам, счётчики крутятся, иллюстрации рисуются, карточки причин складываются стопкой; «Конфиденциальность» открывается текстом внизу страницы; меню и плавающая панель спрятаны |
| Отзывы | проверены на временных тестовых картинках (в проект не попали): лента и свайп на телефоне, сетка на компьютере, просмотр крупно, стрелки/Esc/свайп, фокус возвращается, пункт меню и номера разделов меняются сами. Сейчас скриншотов нет — блока на сайте нет |
| Взаимодействие | меню (и Esc), ползунок до/после — мышью и стрелками, магнитные кнопки, курсор с подписями, окно «Конфиденциальность» (Esc, фокус), галерея; ни одной «битой» ссылки |
| Слабое устройство | при медленных кадрах сайт сам облегчается (24 ресницы, «шёлк» в меньшем разрешении); без видеоускорения «шёлк» — статичный кадр |
| Lighthouse, мобильный (`dist/`, со сжатием как на хостинге) | Performance 83–84 (три прогона: 76, 83, 84; во 2-й версии было 86 — добавились анимации и иллюстрации), Accessibility 100, Best Practices 100, SEO 100; сдвиг макета 0 |

Не проверено вживую: Safari на iPhone (в этой среде только Chromium). Сборка рассчитана на Safari 12+
(скрипты — ES2017, стили — без `@layer`). Ролик — MP4/H.264: его играют Safari, Chrome и Android; тестовый
Chromium без этого кодека его не воспроизводит, поэтому на месте ролика стоит кадр-постер.

## Чек-лист РКН 2026 — как с ним сайт

Сайт для мастера в Минске, а чек-лист — про российские требования. Сайт собран так, что пункты чек-листа
соблюдены или к нему не относятся: главное — **сайт не собирает персональные данные**. Это сверка по чек-листу,
а не юридическое заключение.

| Раздел чек-листа | Как на сайте |
|---|---|
| 1. Реквизиты владельца в подвале | Поле `requisites` в `src/site.config.ts` — выводится в подвале на странице, как только заполнено. **Нужны данные от неё.** |
| 2. Политика обработки ПДн, сквозная ссылка | В подвале — «Конфиденциальность»: честное описание, что сайт ничего не собирает (нет форм, cookie, аналитики, пикселей), что хранится в браузере (отметка «заставка просмотрена») и куда ведут кнопки. Работает и без скриптов. Оферта и договоры поручения не нужны: нет оплаты и не передаются заявки. |
| 3. Формы и согласия | Форм нет вообще — только кнопки-ссылки на мессенджеры. Галочек и согласий не требуется. |
| 4. Cookie и аналитика | Cookie, счётчиков и трекинга нет → баннер не нужен. |
| 5. Локализация и иностранный софт | Нет Google Analytics, Tag Manager, reCAPTCHA, пикселей Meta, внешних шрифтов и CDN — шрифты и скрипты внутри сайта. Хостинг на Timeweb — сервер в РФ. Ссылки на Instagram — просто ссылки, без кода Meta на странице. |
| 6. Реестр операторов РКН | Чек-лист связывает уведомление с формой заявки на сайте; форм здесь нет. Появится форма — понадобится уведомление. |
| 7. Русский язык | Весь текст на русском. Латиница — только название-логотип и названия сервисов (Instagram, Telegram, WhatsApp); подпись к ролику «expressive eyes!» дана с переводом. Закон о русском языке — российский; если сайт должен ему соответствовать, латинское название без зарегистрированного товарного знака лучше продублировать по-русски (например, «Лэш»). |
| 7. Доступность (ГОСТ Р 52872-2019) | Alt у всех фото, контраст текста ≥ 4,5:1 (Lighthouse Accessibility 100), масштабирование не запрещено, управление с клавиатуры, видимый фокус, режим «уменьшить движение». |
| 7. HTTPS | Включается на хостинге: бесплатный Let's Encrypt + перенаправление на HTTPS (шаг 4 в README). |

Если однажды появится форма заявки, понадобятся: отдельная политика ПДн, пустой чекбокс согласия, сервер в РФ
для данных, уведомление в РКН — по чек-листу, разделы 2–3 и 6.

## «Папка читов» — финальная проверка перед публикацией

| Пункт | Как на сайте |
|---|---|
| С первого взгляда понятно главное | Первый экран: «Ресницы, которые поднимают взгляд», макро-фото, кнопка «Записаться» |
| Заголовок читается на телефоне | Крупная антиква, проверено на 360–390 px и горизонтально |
| Шрифты с кириллицей | Cormorant Garamond + Manrope (кириллица + латиница), локально |
| Размеры разделяют заголовки, пояснения, подписи | Три уровня: заголовки 2,6–8,6 rem, текст ≥ 16 px, подписи-метки с номерами разделов |
| Акцент выделяет важное | Фиолетовый — только акценты и главные кнопки |
| Текст различим на фоне | Под текстом «шёлк» приглушён, Lighthouse: контраст без ошибок |
| Иконки в одном стиле | Один набор тонких контурных иконок |
| Отступы последовательны | Единые поля и ритм секций |
| Изображения чёткие и не растянуты | WebP не больше родного размера; в «миндале» фото уменьшено, а не растянуто |
| Декор и анимация помогают | Анимации объясняют процедуру (валик → подъём), до/после, шаги; есть режим без движения |
| Кнопки ведут туда, куда ждут | Проверены все ссылки; пустые каналы записи не показываются |
| Условия использования материалов | Фото и тексты — её собственные посты; шрифты — открытые лицензии (OFL); шейдер и графика написаны с нуля |
| Просмотрено в формате аудитории | Телефоны 360–390 px, горизонтально 844×390, компьютер 1280–1440 |
