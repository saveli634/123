# Отчёт: сайт «Ночной глянец»

## Что сделано

Одностраничный сайт мастера по ламинированию и наращиванию ресниц в Минске, по ТЗ из `PROMPT.md`:
интро с «пишущимся» названием → первый экран с макро-фото в форме «глаз-капли» → закреплённая сцена
«Подъём» (ресницы поднимаются при прокрутке) → до/после с ползунком → услуги → как проходит
ламинирование (горизонтальный таймлайн) → почему ко мне → работы (галерея + ролик) → запись → подвал.
Адаптирован под iPhone и Android в вертикальной и горизонтальной ориентации: все эффекты работают и на
телефоне, а не урезаны.

## Что проверено

Скриншоты Playwright (Chromium) на 1440×900, 1280×800, 390×844, 375×667, 360×780, 844×390 (телефон
горизонтально); сцена «Подъём» — на прогрессе 0 / 0,33 / 0,66 / 1.

| Режим | Результат |
|---|---|
| Обычный (хостинг, `dist/`) | всё работает; нет горизонтальной прокрутки; ошибок и предупреждений в консоли нет |
| Файл с диска (`sait.html`, `file://`) | то же; ролик встроен и передаётся в плеер целиком |
| «Уменьшить движение» | без интро, закреплённых сцен и параллакса; весь текст и фото видны сразу |
| Без JavaScript (так выглядит предпросмотр файла на iPhone) | весь текст и фото на месте, «Подъём» — статичной картинкой; нерабочие без скриптов меню и плавающая панель спрятаны |
| Взаимодействие | меню открывается/закрывается (и по Esc), пункты ведут к разделам; ползунок до/после — мышью и стрелками; магнитные кнопки; галерея листается кнопками; ни одной «битой» ссылки |
| Слабое устройство (процессор замедлен в 20 раз) | сайт сам переходит на облегчённый режим (24 ресницы, без свечения) |
| Lighthouse, мобильный (версия для хостинга, со сжатием как на хостинге) | Performance 87–88, Accessibility 100, Best Practices 100, SEO 100; сдвиг макета 0 |

Не проверено вживую: Safari на iPhone (в этой среде есть только Chromium). Сборка рассчитана на Safari 12+
(скрипты понижены до ES2017, стили — до совместимого синтаксиса, без `@layer`). Ролик в формате MP4/H.264 —
его играют Safari, Chrome и Android; тестовый Chromium без этого кодека его не воспроизводит, поэтому
в галерее на месте ролика всегда стоит кадр-постер.
