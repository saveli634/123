# Queen Bee Boheme Residence — сайт салона красоты

Одностраничный сайт: Vite + React + TypeScript + Tailwind CSS v4, Three.js (лениво), Lenis.
Шрифты Cormorant Garamond 500/600 + курсив и Manrope 400/600 (@fontsource, только кириллица и латиница).

Отчёт для владельца (что сделано, что проверено, что заполнить) — `ОТЧЁТ.md`.
Готовые файлы — `deliverables/` (`site.html`, `queenbee-dist.zip`, скриншоты).

## Команды

```bash
npm install
npm run dev            # разработка, http://localhost:5173 (?dev=1 — панель недостающих данных)
npm run build          # dist/ — для хостинга: пререндер, CSS встроен в HTML, совместимость Safari 12+
npm run build:single   # dist-single/index.html и копия site.html — один файл, до 5 МБ
npm run build:release  # то же, но падает, пока не заполнен CONFIG и не подтверждены согласия
npm run images         # пересобрать фото из assets-src/ (sharp: грейд, WebP, JPG/PNG-запаска)
npm run renders        # при запущенном dev: рендеры сцены для устройств без WebGL 2 + og-image
npm run fonts          # пересобрать src/fonts.css
```

## Где что

- `src/config.ts` — **CONFIG**: город, адрес, часы, телефон, WhatsApp, Instagram, карта, услуги, флаги согласий.
- `src/content/copy.ts` — все тексты и этапы сцены (у каждой строки — источник).
- `src/content/media.ts` — порядок и маски «Стены работ», интерьеры, фильтры.
- `src/three/` — сцена «Зеркало образа»: зеркало и кольцо света, стекло-шейдер, помада, кисть,
  гребень, шпилька, пряди, частицы. `src/lib/stageController.ts` — прокрутка → этапы → сцена.
- `assets-src/` — исходные кадры и `manifest.csv` (точки лица focusX/focusY), `renders/` — рендеры сцены.

## Как устроена главная сцена

- Одна фиксированная канва от первого экрана до конца закреплённого блока (500svh).
  Зеркало первого экрана сначала нарисовано на CSS/SVG (видно без JS и без WebGL);
  3D встаёт ровно на его место (та же геометрия и кадрирование по точке лица).
- 3D загружается по первому действию человека (движение мыши, касание, прокрутка).
  До этого — то же зеркало на CSS. Так первый экран открывается быстро (Lighthouse).
- Без WebGL 2 — готовые рендеры той же сцены (по одному на этап 0–4).
- Reduced motion и без JavaScript — этапы идут обычными блоками с фото, зеркало статично.
- Медленно (<40 к/с за первые 2 с) — ниже pixelRatio, половина прядей и частиц, без bloom.
- Рисуется только пока блок на экране; при скрытой вкладке — остановка.
