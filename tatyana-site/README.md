# Анна — «Карта неба». Многостраничный сайт

Сайт Анны: нумерологический расчёт по дате рождения, натальная карта и творчество — стихи и авторские песни, написанные под личные истории.
Космический фиолетовый, тонкая золотая графика, живое звёздное небо. Всё, кроме её фотографий, нарисовано кодом.

- **`sait.html`** — весь сайт одним файлом вместе с песнями (≈ 17 МБ): открывается двойным щелчком, работает без интернета. Страницы внутри переключаются через меню (`sait.html#/pesni` и т. п.). Песни в нём — облегчённые копии, см. «Звук».
- **`dist/`** — версия для хостинга (`npm run build`): шесть настоящих страниц, песни в папке `audio/`. Подходит для любого статического хостинга, в том числе в подпапке (все пути относительные).
- `brief/` — ТЗ, её тексты, расшифровка голосовых, исходники песен (исходники и расшифровки песен в git не хранятся — они личные).

> **Что не хранится в git.** Репозиторий открытый, поэтому песни (`src/assets/audio/*.mp3`), фото Анны (`src/assets/photos/anna-*.jpg`) и собранный `sait.html` (в нём фото и песни) сюда не загружаются — они передаются заказчику отдельно. Чтобы собрать полный сайт, положите их в эти папки и выполните `npm run build` / `npm run build:single`. Без них проект тоже собирается: фото просто не показываются, а на странице «Песни» вместо плеера — список песен.

> **iPhone и мессенджеры.** Во встроенном предпросмотре Telegram, WhatsApp и «Файлов» скрипты не запускаются: сайт будет статичным (все страницы друг под другом, без анимации, калькулятора и звука). Открывайте в Safari/Chrome или выложите `dist/` на хостинг.

## Как соединены сферы

Анна просила совместить в одном сайте астрологию, нумерологию и творчество. Общая метафора — «музыка небесных сфер»: карта — небо, число — его ритм, слово и песня — голос. Четыре планеты **Карта · Число · Слово · Песня** — это меню на первом экране, значки страниц и разделов, их орбиты медленно движутся на фоне всего сайта. Все сферы встречаются на странице «Подарки».

## Звук

Шесть песен сжаты в mp3 128 кбит/с (всего ≈ 23 МБ) и лежат в `dist/audio/`. Каждая загружается, только когда нажмут «Слушать». Одновременно играет одна песня; есть пауза, перемотка, громкость и обычный встроенный плеер как запасной вариант. Текстов песен на сайте нет: расшифровки автоматические, с ошибками (лежат в `brief/content/pesni/raspoznavanie/`, в git не хранятся).

В `sait.html` песни тоже есть — по просьбе заказчика (в ТЗ было «встраивать, только если не больше 2 МБ»). Чтобы файл не вырос до 30 МБ, туда кладутся облегчённые копии: mp3 64 кбит/с, моно (≈ 12 МБ; звучат чуть проще, чем на хостинге). Их добавляет `scripts/embed-audio.mjs` в самый конец файла, поэтому страница показывается сразу, а песня распаковывается только по нажатию «Слушать». С диска кольцо вокруг кнопки пульсирует само, а не в такт музыке: браузеры не дают анализировать звук у открытых с диска файлов.

**Добавить или заменить песню:** положить файл в `brief/content/pesni/` и рядом `.txt` с тем же именем (первая строка — название, через « · » можно указать стиль, дальше — текст песни), выполнить `npm run songs`, затем `npm run build`.

## Что нужно от Анны

1. **Согласия на публикацию песен.** В каждой — имена и личные подробности (семья, коллеги, муж, дети, внуки). Нужно её «да» и, по-хорошему, согласие тех, кому песни посвящены. Без согласия песни можно убрать одной командой (см. «Звук»).
2. **Тексты песен** — оригиналы (расшифровки с ошибками: «Маркшейдер», имена в песне бабушке и т. д.).
3. **Канал записи**: Instagram astro_numero_anna, WhatsApp или другой — без этого кнопок записи на сайте нет.
4. **Подарочные наборы**: состав, цены, сроки; названия книг («Кто я», «Для чего я здесь» — она сказала «например»).
5. **Видеоролики** (годовщина венчания, День учителя) не опубликованы: на них лица, в том числе детей класса. Можно добавить с согласием родителей и учителя.
6. **Стих ко Дню Победы** не поставлен (политическое содержание) — если она хочет, добавить можно.
7. **Сертификат** с группового фото: если хочет строку «окончила курс натальной астрологии», нужно точное название; групповое фото не используется.
8. **Фото**: использованы три — портрет в жёлтом, с кувшином, у сада. Согласовать.
9. **Схема подсчёта чисел** и границы знаков (см. `src/lib/numerology.ts`).
10. **Опечатки в стихах** (текст на сайте дословный): «ирах» → «играх», «скушны» → «скучны», «не лёгкий» → «нелёгкий», «на пол пути» → «на полпути», «телом своих рук» → «теплом»?, «С 5 летием» → «С 5-летием», «вернуться к вам снова» → «вернутся», «школо- правительницу», лишние пробелы перед запятыми, дефисы вместо тире. Эмодзи убраны; «‼️», «⁉️», «❗» стали «!!», «?!», «!». В строке «ну просто 🔥» эмодзи заменяло слово.
11. **Дисклеймер в подвале** — согласовать формулировку.

## Отличия от ТЗ (осознанно)

- **Многостраничный сайт** вместо одностраничного — по просьбе заказчика. Шесть страниц на хостинге; в `sait.html` — те же страницы внутри одного файла.
- **Фото Анны** вместо «визуалов только кодом» — она прислала фото.
- **Раздел «Песни» виден всегда** (в ТЗ — скрыт без файлов): песни присланы.
- **Закрепление сцен** — `position: sticky` в `svh` + прогресс от ScrollTrigger (на телефонах ничего не скачет).
- **Tailwind** — сброс стилей, тема и `sr-only`; сами компоненты — обычный CSS.
- **Lighthouse главной — 80** при цели 85: интро (по ТЗ) и портрет на первом экране. Остальные страницы — 86–91.

## Где править

- `src/data/site.config.ts` — фамилия, каналы записи, город, цены.
- `src/data/pages.json` — заголовки и описания страниц.
- `src/components/Pages.tsx` — состав каждой страницы и тексты первых экранов.
- `src/components/HomeBlocks.tsx`, `GiftBlocks.tsx` — «Обо мне», карточки сфер, подарки.
- `src/data/content.ts` — расчёты, тезисы, шаги подарка; стихи — `brief/content/*.md` → `npm run poems`.
- `src/assets/photos/` — фото (`src/data/photos.ts`).
- `src/lib/numerology.ts` — схема подсчёта.
