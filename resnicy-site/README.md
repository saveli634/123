# «Ночной глянец» — сайт мастера по ресницам (Минск)

Одностраничный сайт-визитка: ламинирование и наращивание ресниц. Чернильно-фиолетовая сцена с живым
«шёлком», белая каллиграфия из её же постов, ресница — главный мотив. Все тексты — только из её подписей
(см. `REPORT.md`, таблица «фраза → источник»).

## Что отдать

| Файл | Зачем |
|---|---|
| `sait.html` | **Один файл** (1,7 МБ): всё встроено — фото, ролик, шрифты. Открывается двойным щелчком без интернета. Можно переслать. |
| `timeweb/index.html` | Тот же файл под именем `index.html` — для выкладки на Timeweb по шагам ниже. |
| `dist/` | Версия для хостинга с отдельными файлами фото и ролика — грузится быстрее. Залить папку целиком в `public_html` (или на Netlify Drop, GitHub Pages). |

**Важно про телефон.** В предпросмотре (приложение «Файлы» на iPhone, просмотр вложения в Telegram/WhatsApp)
скрипты не работают: видны тексты и фото, но без анимаций. Чтобы увидеть всё — открыть файл в Safari/Chrome
(«Поделиться» → «Открыть в…») или выложить на хостинг и открыть ссылку.

## Как выложить на Timeweb (≈10 минут)

1. **Регистрация.** hosting.timeweb.ru → «Регистрация» (имя и e-mail или телефон). Сразу включится 10 дней
   бесплатного теста, карту привязывать не нужно.
2. **Загрузка.** Слева «Файловый менеджер» → папка сайта → `public_html`. Удалить заглушку хостинга
   (`index.html` или `index.php`). «Загрузить файлы» → `timeweb/index.html`. Файл должен называться строго
   `index.html` и лежать прямо в `public_html`. Проверить по техническому адресу вида `логин.tw1.ru`.
   *Вариант быстрее:* загрузить вместо него всё содержимое папки `dist/` (с подпапками `assets/` и `media/`).
3. **Домен** (по желанию, `.ru` ≈ 200–250 ₽/год). «Домены и поддомены» → «Зарегистрировать домен» → заполнить
   анкету владельца → оплатить → шестерёнка → «Привязать к сайту». DNS обновляется от 20 минут до 2 часов.
4. **HTTPS.** «SSL-сертификаты» → бесплатный Let's Encrypt → выбрать домен → «Установить» → включить
   «Перенаправлять с HTTP на HTTPS». Выпускать сертификат — только когда домен уже открывает сайт.
5. После подключения домена — вписать адрес в `index.html` (тег `canonical` и полный адрес `og:image`,
   место отмечено комментарием), чтобы превью ссылки в мессенджерах было с фото.

## Где править данные

Всё в одном месте — `src/site.config.ts`:

- `brand` — название латиницей (сейчас «Lash» — её надпись из поста; есть готовая векторная «Angel»; любое
  другое слово будет набрано каллиграфическим шрифтом);
- `masterName` — имя (пусто — не выводится);
- `booking` — Instagram, Telegram, WhatsApp, телефон: кнопка появляется только у заполненного канала,
  «Позвонить» — только если есть номер. Пока всё пусто, кнопка записи ведёт на её пост в Instagram;
- `requisites` — реквизиты в подвал (ИП/самозанятая, УНП/ИНН). Пусто — строка не выводится;
- `address` — адрес/район (пусто — блок «Где принимаю» скрыт);
- `prices` — цены (пустой список — блок «Цены» скрыт; вёрстка готова).

После правки: `npm run build:all` — обновятся `dist/`, `sait.html` и `timeweb/index.html`.

## Сборка

```bash
npm install
npm run dev          # просмотр с автообновлением
npm run build        # dist/ — для хостинга (разметка готова заранее: текст виден без скриптов)
npm run build:single # sait.html и timeweb/index.html — один файл
npm run build:all    # все варианты
npm run media        # пересобрать фото, ролик и векторные надписи из assets-src/ (нужны Pillow и ffmpeg)
npm run fonts        # пересобрать src/fonts.css (только кириллица + латиница)
```

Стек: Vite + React + TypeScript + Tailwind, GSAP + ScrollTrigger, Lenis (плавная прокрутка только для
мыши/тачпада), WebGL без библиотек. Без аналитики, форм, cookie, внешних скриптов, шрифтов и CDN — всё локально.

## Как устроено

- **Интро** (≤ 1,5 с, только первый заход в сессии): название «пишется» штрихом, «веки» раскрываются.
  Целиком на CSS — не ждёт скриптов. Пропускается при «уменьшить движение».
- **Первый экран** (`Hero.tsx`): живой фон «шёлк» (`lib/silk.ts`, WebGL-шейдер: атласные складки с жемчужными
  бликами, тянутся за курсором, на телефоне плавают сами). Макро-фото — в «глазе-миндале» (пересечение двух
  кругов), рядом вращается круговая надпись. При прокрутке миндаль раскрывается на весь экран, строки заголовка
  разъезжаются, появляется «Процедура — всего 1 час», кадр уходит в темноту — и начинается «Подъём».
  Без WebGL, без видеоускорения и при «уменьшить движение» — статичный кадр или CSS-градиент.
- **«Подъём»** (`LiftScene.tsx`, `lib/lashes.ts`, `lib/liftRenderer.ts`): закреплённая сцена на 280svh,
  canvas 2D. Ресницы лежат → выкладываются на валик → поднимаются, глаз открывается, на кончиках блики →
  «Поднимаю взгляд за час». Если кадры медленные (< ~45 fps две секунды подряд) — 24 ресницы вместо 40,
  «шёлк» в меньшем разрешении. Без скриптов — та же геометрия статичной SVG-картинкой.
- **До/после**: фото 003 разрезано по белой полосе и выровнено по зрачку. Ползунок — мышь, палец, стрелки;
  при входе в секцию «после» проявляется само.
- **Услуги**: карточки с фото (параллакс внутри кадра), 3D-наклон и голографическая кромка за курсором,
  на телефоне — покачивание.
- **Процедура**: горизонтальный закреплённый таймлайн на светлом фоне, линия-ресница зажигает шаги.
- **Почему ко мне**: карточки складываются стопкой при прокрутке, «60 минут» и «1 месяц» — счётчики-барабаны.
- **Работы**: перетаскивание с инерцией, фото внутри кадров смещаются (глубина), ролик играет только на экране.
- **Запись**: «шёлк» и огромная каллиграфия; **подвал**: название «пишется» при прокрутке, время в Минске,
  «Конфиденциальность» (окно; без скриптов — текст по ссылке внизу страницы), реквизиты.
- Ещё: заголовки проявляются по словам, фирменный курсор (кольцо с подписями «тяни», «листай»), магнитные
  кнопки с бликом, прогресс-ресница сверху, бегущая лента, нижняя панель «Записаться» на телефоне.
- Закреплённые сцены сделаны на `position: sticky` + единицы `svh` — без скачков, когда прячется адресная строка.
